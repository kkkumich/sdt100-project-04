## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_loops.Main
java -cp build part2_uppercase.Main
java -cp build part3_reverse.Main
java -cp build part4_repeated_recommender.Main
```

## Что показать на защите

Покажи while, do-while, for, вложенный цикл, обход строки, uppercase, разворот через charAt и повтор диалога по Y/y. Затем введи N.

## Как объяснить

while проверяет условие до выполнения, do-while — после, поэтому выполняется хотя бы один раз. for удобен для известного количества повторений. В развороте строк индекс идёт от length()-1 до 0. Вложенные циклы выполняют внутренний цикл для каждой итерации внешнего.

## Возможные вопросы

- **Почему последний индекс length()-1?** Индексация начинается с нуля.
- **Что будет без изменения счётчика?** Условие может никогда не стать ложным, получится бесконечный цикл.
- **Почему в обратном отсчёте нет 6?** Именно такая последовательность указана в условии. Использован i-- и явный пропуск 6; если это опечатка преподавателя, условие if(i!=6) можно убрать.

## Замечания

Разворот через charAt отвечает учебному условию; для сложных Unicode-символов, состоящих из нескольких кодовых единиц, он не является универсальным текстовым алгоритмом.
